Transform selection

Move: X/Y/Z are offsets in world axes. Set only Z to raise or lower the selection. G: move · R: rotate · S: scale. Drag an axis arrow in the scene; XY/XZ/YZ planes appear near the centre, the centre diamond moves in the view plane. Click a vertex to move just that point. Escape returns to selection.

Rotate and scale around the selection centre. Each operation is one undo step.

Layers

Rename uses Name. Removing a layer moves its entities to default.

Help

Line, rectangle and circle use two clicks in the selected plane. Z sets the plane origin height. Point and box use one click. Polyline and polygon finish with Enter or Finish path. Undo removes a pending point. Drag a grip in its editing plane. Circle grips use the circle plane; mesh grips use the selected plane. Mesh corners remain shared between faces. Escape cancels.
